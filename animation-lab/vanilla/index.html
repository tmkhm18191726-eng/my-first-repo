Web Animations API

JavaScript の element.animate() で作ったアニメーションは、 あとから再生・逆再生・速度変更ができます。

CANVAS

Canvas 描画

requestAnimationFrame で 1 フレームずつ自分で描くので、 粒子どうしの距離で線を引くような自由な表現ができます。マウス（指）を近づけてみてください。

-- fps
SVG

SVG パスを描く

stroke-dashoffset で線が伸びていく表現。 getPointAtLength() を使って、先端に点を走らせています。

4 つとも仕組みが違います。 CSS は書くのが一番速く、 WAAPI は JS から細かく操作でき、 Canvas は数千個の粒子でも軽く、 SVG は拡大しても輪郭がボケません。 作りたい絵に合わせて選びます。
