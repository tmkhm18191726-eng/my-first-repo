# YouTube サムネイル ダウンローダー（ユーザースクリプト版）

Tampermonkey / Violentmonkey / Greasemonkey で動く 1 ファイルのユーザースクリプトです。
拡張機能版（`../youtube-thumbnail-downloader/`）と同じことができますが、
**すでにユーザースクリプトマネージャを入れているならこちらのほうが手軽**です。

| | ユーザースクリプト版 | 拡張機能版 |
| --- | --- | --- |
| 導入 | ファイルを開いて「インストール」 | デベロッパーモードでフォルダを読み込む |
| フォルダの保管 | 不要 | **必要**（消すと無効になる） |
| 端末間の同期 | マネージャの同期機能で可能 | 手動 |
| 操作 | サムネイルにホバー / Alt+T | ツールバーのアイコン / 右クリック |
| 更新 | ファイルを編集して保存 | 編集後に再読み込みボタン |

## インストール

1. Tampermonkey（または Violentmonkey / Greasemonkey）を入れておく
2. `youtube-thumbnail-downloader.user.js` を開く
   - GitHub 上なら **Raw** ボタンを押すと、Tampermonkey がインストール画面を出します
   - ローカルのファイルなら、Tampermonkey のダッシュボード → **ユーティリティ** → **ファイルからインストール**
3. 内容を確認して **インストール**

## 使い方

### サムネイルにマウスを乗せる

トップページ・検索結果・関連動画・チャンネルページなど、サムネイルが並んでいる場所で
画像にマウスを乗せると、右上に **↓** ボタンが出ます。

- **クリック** … その動画で一番大きいサムネイルを保存
- **Shift + クリック** … 解像度を選ぶ画面を開く

タイトル文字だけのリンクにはボタンは出ません（誤操作を防ぐため）。

### 視聴ページ

- **Alt + T** … 今見ている動画のサムネイルを保存
- 検索欄などに入力しているときは反応しません

### Tampermonkey のメニュー

拡張機能アイコン → このスクリプト名の下に項目が出ます。

- このページの動画のサムネイルを保存
- 解像度を選んで保存
- 保存形式を切り替え（JPG ⇄ WebP。設定は保持されます）

## 保存されるもの

ファイル名は `動画タイトル_動画ID_解像度.jpg` です。
Windows で使えない文字（`\ / : * ? " < > |`）は自動で取り除かれます。

| 解像度キー | サイズ | 備考 |
| --- | --- | --- |
| `maxresdefault` | 1280 × 720 | 無い動画もある |
| `sddefault` | 640 × 480 | 無い動画もある |
| `hqdefault` | 480 × 360 | 必ず存在する |
| `mqdefault` | 320 × 180 | |
| `default` | 120 × 90 | |

存在しない解像度をリクエストすると、YouTube は 404 を返すか 120×90 のグレー画像を返します。
このスクリプトは読み込めた画像の実寸を見て両方のケースを判定し、
**実際に存在する中で一番大きいもの**を選びます。選択画面では無いものがグレーアウトします。

## 権限（`@grant`）について

| 権限 | 用途 |
| --- | --- |
| `GM_download` | 画像を保存する（主経路） |
| `GM_xmlhttpRequest` + `@connect i.ytimg.com` | `GM_download` が使えない環境での保存 |
| `GM_registerMenuCommand` | マネージャのメニューに項目を追加する |
| `GM_setValue` / `GM_getValue` | JPG / WebP の選択を覚える |
| `GM_addStyle` | ボタンやダイアログの見た目を当てる |

アクセスするのは `i.ytimg.com`（サムネイル画像）だけです。閲覧履歴の収集や外部送信は行いません。

## うまく動かないとき

- **ボタンが出ない** … YouTube の DOM 変更でサムネイルのリンク構造が変わった可能性があります。
  スクリプト内の `LINK_SELECTOR` と `CARD_SELECTOR` を調整してください。
- **保存されない** … Tampermonkey の設定でダウンロードモードが「ブラウザ API」になっているか確認してください。
  ダメな場合も `GM_xmlhttpRequest` 経由の経路に自動で切り替わります。
- **Alt + T が効かない** … 他の拡張機能と衝突していることがあります。
  スクリプト末尾の `keydown` のところでキーを変更できます。

## 開発

```bash
# ダミーの YouTube ページ上で動作を確認する（playwright が必要）
node test/test-userscript.mjs
```

グローバルインストールの playwright を使う場合は `NODE_PATH` を指定してください。

```bash
NODE_PATH="$(npm root -g)" node test/test-userscript.mjs
```

## 注意

サムネイル画像の著作権は各動画の権利者にあります。私的利用の範囲を超える使い方（無断転載など）はしないでください。
