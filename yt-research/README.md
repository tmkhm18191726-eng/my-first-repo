# YouTube リサーチ

「開設して間もないのに伸びているチャンネル」を条件から一気に探すためのツールです。
タイトルキーワード・チャンネル開設時期・再生数・動画公開日・登録者数を組み合わせて検索し、
結果をチャンネル単位でまとめて表示します。

## できること

- **条件を組み合わせた検索**
  - タイトルキーワード（スペース区切りで AND、タイトルに含むものだけに絞るオプション付き）
  - チャンネル開設が N 日以内
  - 動画公開日が N 日以内
  - 再生数の下限
  - 登録者数の下限・上限
- **チャンネル単位の集計** — 何本ヒットしたか、最高再生数、合計再生数を表示。動画一覧は開閉できます
- **伸びの指標** — 「1日あたり再生数」（再生数 ÷ 公開からの日数）で並べ替えられるので、
  公開直後の勢いがあるチャンネルを見つけやすくなっています
- **検索履歴** — 過去30件の条件と結果を端末内に保存。API クォータを使わずに見返せます

## 使いはじめ（初回だけ API キーの用意が必要）

1. [Google Cloud Console](https://console.cloud.google.com/projectcreate) でプロジェクトを作る
2. [YouTube Data API v3](https://console.cloud.google.com/apis/library/youtube.googleapis.com) を有効化する
3. 「認証情報」→「認証情報を作成」→「APIキー」でキーを発行
4. 発行したキーの制限を設定（推奨）
   - APIの制限: YouTube Data API v3 のみ
   - アプリケーションの制限: HTTP リファラーで、このアプリを開く URL のみ
5. アプリの「設定」タブでキーを貼り付けて保存

キーはブラウザの localStorage にだけ保存され、リポジトリやビルド成果物には含まれません。
検索リクエストは端末から直接 YouTube API に送られます。

## API クォータについて

YouTube Data API の無料枠は 1 日 10,000 クォータ（日本時間の17時ごろにリセット）です。

| 呼び出し | コスト |
| --- | --- |
| `search.list`（1ページ50件） | 100 |
| `videos.list` | 1 |
| `channels.list` | 1 |

1ページ取得の検索で約 102 クォータなので、**1日およそ 95 回**検索できます。
検索フォームの「詳細設定」で取得ページ数を増やすとヒット数は増えますが、その分クォータも増えます。

## 開発

```bash
npm install
npm run dev      # 開発サーバー
npm run build    # 型チェック + 本番ビルド
npm run lint     # oxlint
npm run preview  # ビルド結果の確認
```

## 仕組み

1. `search.list` でキーワードに合う動画 ID を集める（最大 5 ページ / 250件）
2. `videos.list` で再生数・公開日などの統計を取得
3. `channels.list` で登録者数・チャンネル開設日を取得
4. 取得したデータをブラウザ側で絞り込み、チャンネル単位にまとめる

チャンネル開設日や再生数は API の検索条件として指定できないため、
まとめて取得してからクライアント側でフィルタする作りになっています。

## 制限事項

- `search.list` はタイトルだけでなく説明文やタグも対象にするため、「タイトルに含む動画だけに絞る」を
  オンにしても、取得後のフィルタで落ちる分だけヒット数が減ります
- 1回の検索で見られるのは最大 250 件です。もっと広く探したいときはキーワードを分けて検索してください
- 登録者数を非公開にしているチャンネルは、登録者数で絞り込むと結果から外れます
