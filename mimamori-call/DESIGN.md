# 見守り通話アプリ 設計書

子どもの帰宅時に、親のスマートフォンから自宅の Windows ノート PC へ音声で話しかけられる
家族用の見守り Web アプリです。

## 1. 何を作るか

自宅の Windows ノート PC を「音声通話の受け手」として常時待機させ、親の iPhone から Web ページを
開いて「接続」を押すだけで、双方向の音声通話ができるアプリです。
**録音は一切しません。** 認証された親だけが接続できます。

```
[親のiPhone/Safari] ──HTTPS──┐
                              ├─→ [Cloudflare Workers]
[自宅WindowsノートPC/Chrome]─┘      ├ Next.js（画面の配信）
        │                            ├ WebSocket（Durable Object＝つなぎ役）
        │                            ├ Cloudflare Access（本人確認）
        │                            └ D1（接続履歴：日時と成否のみ）
        │
        └──────── WebRTC 音声（端末どうしが直接やりとり）────────┘
                  ※音声はCloudflareを通らない／どこにも保存されない
```

声そのものはサーバーを通りません。Cloudflare は「相手の居場所を教え合う電話交換手」の役割だけを
担い、音声は iPhone と Windows PC の間を直接流れます。これが「録音・保存しない」を
仕組みとして担保します。

## 2. 画面の構成

| URL        | 誰が使うか        | 内容                                             |
| ---------- | ----------------- | ------------------------------------------------ |
| `/`        | 共通              | 「親用」「自宅PC用」を選ぶだけの入口             |
| `/parent`  | 親（iPhone）      | 大きな「接続」ボタン、状態表示、「通話終了」ボタン |
| `/home`    | 自宅 Windows PC   | 「待機開始」ボタン → 押すと全画面の待機画面へ     |
| `/history` | 親                | 接続履歴（フェーズ3で追加。日時と成功／失敗のみ） |

### 自宅PC の待機画面（家族に見える画面）

- 画面中央に特大文字で **「見守り通話待機中」**
- 通話が始まると画面全体が色替わり（青 → 緑）＋大きく **「通話中」**
- 画面上部に常時 **🔴 マイク使用中** バッジ＋声の大きさメーター
- 着信時は大きなチャイム音が鳴る（気づかないうちに繋がることを防ぐ）

### 日本語の状態表示

`待機していません` / `待機中` / `呼び出し中…` / `接続中…` / `通話中` / `通話を終了しました` /
エラー各種（`マイクを使えません` / `自宅PCが待機していません` / `ネットワークに接続できません` /
`認証が必要です` / `接続に失敗しました`）

すべて **原因と次にやること** をセットで表示します。

### 将来の映像通話への備え

- `peer.ts` は最初から `{ audio: true, video: false }` という設定を受け取る形にする。
  映像を足すときは **この 1 か所を `video: true` にし、画面に `<video>` を出すだけ**。
- 合図のやりとり（シグナリング）は最初から再交渉（renegotiation）対応にしておく。
- 通話画面には映像用の枠を非表示で用意しておく。

## 5. 安全面の設計

| ご要望                       | 設計での対応                                                                                                                                 |
| ---------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| 秘密URLだけに依存しない      | Cloudflare Access のログインを通らないとページ自体が開けない。加えて WebSocket 接続時にサーバー側で本人確認トークンを再検証する               |
| 認証されていない人は接続不可 | Access のポリシーで許可メールアドレスを明示指定。それ以外は全拒否                                                                             |
| HTTPS/WSS のみ               | Cloudflare 経由なので常に HTTPS/WSS。HTTP は自動リダイレクト                                                                                  |
| APIキーを直接書かない        | 秘密情報は `wrangler secret`（本番）と `.dev.vars`（手元、Git 対象外）で管理。`.dev.vars.example` には名前だけを置く                          |
| 無断録音・隠し監視をしない   | 録音機能（MediaRecorder）を一切実装しない。通話中は自宅PCで大音量チャイム＋全画面表示＋マイク使用中バッジが必ず出るため、気づかれずに繋がることが構造的にできない |
| 履歴は日時と成否のみ         | D1 に保存するのは 開始日時 / 終了日時 / 実行者メール / 結果 / 通話秒数 / エラー種別 のみ。音声・映像・文字起こしは保存しない                  |

### 応答方式（決定事項）

**自動応答**を採用する。親が「接続」を押すと自宅PCは自動で応答する。
監視的な利用を防ぐため、以下を必須とする。

- 着信時に大音量のチャイムを鳴らす
- 通話中は画面全体を緑にし、特大文字で「通話中」と表示する
- マイク使用中バッジと音量メーターを常時表示する

## 6. 想定される制限

1. **繋がらない回線がある可能性** — 携帯回線や一部の Wi-Fi では端末どうしの直接接続が塞がれる
   ことがある。その場合は中継サーバー（TURN）が必要。フェーズ2で実測して判断する。
2. **PC が起きていないと着信できない** — スリープ・シャットダウン・停電・回線断のときは繋がらない。
3. **緊急通報の代わりにはならない** — 119/110 の代替にはならない。
4. **iPhone 側の制約** — 通話中に画面をロックしたり他アプリに切り替えると切断される場合がある。
   ホーム画面に追加した PWA では Access のログイン画面が Safari 側で開く場合がある。
5. **自宅PCの再ログイン** — Access のログイン有効期限（最長1か月）が切れると再ログインが必要。
6. **ブラウザが閉じていると着信できない** — プッシュ通知による呼び出しはスコープ外。
7. **録音しないため、後から会話を聞き返すことはできない**（仕様どおり）。
8. **相手の IP アドレスが見える可能性** — WebRTC の性質上、直接接続時はお互いの IP が分かる。
9. **技術的なリスク** — Next.js を Cloudflare Workers で動かすには OpenNext を使う。画像最適化など
   一部の Next.js 機能に制限がある（本アプリでは使わない）。同一 Worker 内で WebSocket を扱う構成が
   難しい場合は、パス単位で Worker を分ける代替案に切り替える。

## 7. 進め方

### フェーズ1：家の中で音声通話ができる最小版

| ステップ | 作るもの                                              |
| -------- | ----------------------------------------------------- |
| 1-1      | プロジェクトの土台、`/parent`・`/home` の画面（見た目） |
| 1-2      | つなぎ役（WebSocket サーバー）                        |
| 1-3      | WebRTC で実際に音声が通る                             |
| 1-4      | HTTPS 化して iPhone ↔ Windows PC で実機テスト         |
| 1-5      | 状態表示・終了ボタン・マイク使用中表示の仕上げ        |

### フェーズ2：外出先から使えるようにする

Cloudflare へ公開 → 外出先（携帯回線）からテスト → 繋がらない場合のみ TURN を追加

### フェーズ3：認証と履歴

Cloudflare Access の設定 → サーバー側での本人確認 → D1 で接続履歴

### フェーズ4：自宅PCの常時運用

Windows 起動時に自動で待機画面を開く手順＋スリープ防止設定を README に記載
