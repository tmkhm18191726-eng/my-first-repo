# 見守り通話（mimamori-call）

子どもの帰宅時に、親のスマートフォンから自宅の Windows ノートパソコンへ
音声で話しかけられる、家族用の見守り Web アプリです。

- **会話は録音も保存もしません。**
- 声は端末どうしで直接やりとりされ、サーバーには残りません。
- 通話中は自宅のパソコンに「通話中」と大きく表示されます。
- 緊急時の通報には使えません。119 番・110 番をご利用ください。

くわしい設計は [DESIGN.md](./DESIGN.md) をご覧ください。

## 動いているか確かめる（1台のパソコンだけでできます）

> ⚠️ **イヤホンを付けてから試してください。** 1台のパソコンで両方の画面を開くと、
> スピーカーの音をマイクが拾ってしまい、キーンという音（ハウリング）が出ます。

1. ウィンドウを2つ開き、片方で `/home`、もう片方で `/parent` を開く
2. `/home` で「待機開始」を押す
   - マイクの使用許可を聞かれるので **「許可」** を選ぶ
   - 「見守り通話待機中」と大きく出る
   - このとき画面上部は「マイクは切れています」のまま（待機中はマイクを使いません）
3. `/parent` に「自宅のパソコン：待機中（呼び出せます）」と出る
4. `/parent` で「接続する」を押す
   - 自宅PC側で **チャイムが鳴る**
   - 両方の画面が「通話中」になり、上部が赤い **「🔴 マイク使用中」** に変わる
   - 声を出すと、赤いバーが左右に動く
5. 「通話を終了する」を押す
   - 自宅PC側は5秒ほどで待機表示に戻り、マイク表示も「切れています」に戻る

つなぎ役の PowerShell を `Ctrl` + `C` で止めると、自宅PC の画面は「準備中…」に変わり、
もう一度 `npm run dev:signal` で起動すると、**何も操作しなくても** 待機中に戻ります。

## iPhone からつないでみる（ステップ1-4）

iPhone の Safari は、`https://` で始まるアドレスでないとマイクを使わせてくれません。
そこで wrangler に内蔵されている **トンネル機能** を使い、自宅パソコンに一時的な https アドレスを作ります。

作業はぜんぶ **自宅の Windows ノートパソコン** で行います。

### ⚠️ 先に必ず：合言葉を決める

トンネルを開くと、そのアドレスは **インターネット上の誰でも開ける状態** になります。
合言葉を設定しないままトンネルを開くと、アドレスを知った人が自宅のマイクにつながってしまいます。

> **順番を必ず守ってください。**
> 1. 合言葉を設定する（この項目）
> 2. アプリを **止めて、起動し直す**（合言葉は起動時に読み込まれるため）
> 3. そのあとでトンネルを開く

インターネットに出すので、**アドレスを知っているだけでは入れないように**します。

```powershell
cd $HOME\my-first-repo\mimamori-call; copy .dev.vars.example .dev.vars; notepad .dev.vars
```

メモ帳が開いたら、`ROOM_SECRET=` の右側に家族で決めた合言葉を書いて保存します。

```
ROOM_SECRET=hanako-taro-2026
```

- 名前や誕生日そのままは避けてください
- このファイルは GitHub には送られません（`.gitignore` に入れてあります）

### cloudflared のインストールは不要です

wrangler にトンネル機能が内蔵されており、必要な道具は初回に自動で入ります。
別途インストールする必要はありません。

### 毎回の手順

**1. 合言葉を設定してから、アプリを起動する**

```powershell
cd $HOME\my-first-repo\mimamori-call; npm run preview
```

> ⏳ **終わるまで1分ほどかかります。** 次の行が出るまで待ってください。
>
> ```
> Ready on http://127.0.0.1:8787
> ```
>
> **この PowerShell は閉じないでください。** 閉じるとアプリも止まります。

起動時に `Using secrets defined in .dev.vars` と出ていれば、合言葉が読み込まれています。

**2. 合言葉が効いているか、先に確かめる**

ブラウザで `http://127.0.0.1:8787/home` を開き、**「合言葉を入力してください」の画面が出ること**を
確認してください。

> 🚨 この画面が出ないままトンネルを開くと、**誰でも自宅のマイクにつながります。**
> 出ない場合は、`.dev.vars` に合言葉が書かれているかを確認し、
> `Ctrl` + `C` で止めてから `npm run preview` で起動し直してください。

**3. トンネルを開く**

`npm run preview` を動かしている PowerShell で、キーボードの **`t`** を1回押します。

しばらくすると、次のようなアドレスと QR コードが表示されます。

```
⬣ Sharing via Cloudflare Tunnel: https://xxxx-xxxx-xxxx.trycloudflare.com/
```

**iPhone のカメラで QR コードを読み取れば、そのまま開けます。**

> ⚠️ このアドレスは、トンネルを開き直すたびに変わります。
> ⚠️ 使い終わったら、**もう一度 `t` を押してトンネルを閉じてください。**

### 3. 自宅のパソコン側

Chrome か Edge で `http://localhost:8787/home` を開きます（トンネルのアドレスではなく、
こちらを使ってください。速くて安定します）。

1. 合言葉を入力する（1回だけ）
2. 「待機開始」を押す
3. マイクの使用許可を **「許可」** にする
4. 「見守り通話待機中」と大きく出れば準備完了

### 4. iPhone 側

**Safari** で、トンネルのアドレスの後ろに `/parent` を付けて開きます。
（QR コードを読み取った場合は、開いた画面で「親用」を選んでください）

```
https://xxxx-xxxx-xxxx.trycloudflare.com/parent
```

1. 合言葉を入力する（1回だけ）
2. 「自宅のパソコン：待機中（呼び出せます）」と出るのを確認する
3. 「接続する」を押す
4. マイクの使用許可を **「許可」** にする

### 5. 確認すること

- [ ] 自宅パソコンで **チャイムが鳴る**
- [ ] 両方の画面が「通話中」になる
- [ ] **iPhone に向かって話すと、パソコンのスピーカーから聞こえる**
- [ ] **パソコンに向かって話すと、iPhone から聞こえる**
- [ ] パソコンの画面上部が赤い「🔴 マイク使用中」になり、声に合わせてバーが動く
- [ ] 「通話を終了する」で両方が終わり、マイク表示が消える

### 6. ホーム画面に追加する（任意）

iPhone の Safari で `/parent` を開いた状態で、下の共有ボタン → **「ホーム画面に追加」**。
アプリのように1タップで開けるようになります。

> ただし、トンネルのアドレスは毎回変わるため、ホーム画面への追加が本当に役立つのは
> フェーズ2（固定のアドレスで公開）からです。

### 7. テストが終わったら

PowerShell で **`t` を押してトンネルを閉じ**、そのあと `Ctrl` + `C` でアプリを止めてください。
トンネルを閉じると、外部からのアドレスは使えなくなります。

## 秘密情報の扱い

パスワードや API キーは、**プログラムの中に直接書きません。**

- 手元で使う値 … `.dev.vars`（`.gitignore` に入っているので GitHub には送られません）
- 公開先で使う値 … `npx wrangler secret put 名前` で Cloudflare に登録します

合言葉（`ROOM_SECRET`）も同じ扱いです。合言葉が正しいかどうかの判定は
**必ずサーバー側で行っています**ので、画面側のプログラムを書き換えても通り抜けられません。

`.dev.vars.example` には「どんな名前の設定が必要か」だけを書いてあります。
使うときはこれをコピーしてください。

```powershell
copy .dev.vars.example .dev.vars
```

※ フェーズ1 の段階では、まだ何も設定する必要はありません。

## 通話の流れ

```
親のスマホ                つなぎ役サーバー              自宅のパソコン
   │                    (Cloudflare Workers)              │
   │─── 接続する ──────────────▶│                          │
   │                            │──── 呼び出し ──────────▶│
   │                            │                    自動で応答
   │◀─── 相手が応答した ─────────│                          │
   │                                                       │
   └────────── ここから先は端末どうしが直接やりとり ────────┘
                 （音声。サーバーは通りません）
```

つなぎ役サーバーを通るのは「どこに繋げばよいか」という合図だけです。
**声そのものはサーバーを通らず、どこにも保存されません。**

## 録音していないことの確かめ方

このアプリには、音を保存するためのしくみ（`MediaRecorder`）が**一行も入っていません。**
次のコマンドで確認できます（説明文のコメント以外、何も出てきません）。

```powershell
findstr /s /i "MediaRecorder" src\*
```
