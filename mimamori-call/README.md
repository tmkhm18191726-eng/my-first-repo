# 見守り通話（mimamori-call）

子どもの帰宅時に、親のスマートフォンから自宅の Windows ノートパソコンへ
音声で話しかけられる、家族用の見守り Web アプリです。

- **会話は録音も保存もしません。**
- 声は端末どうしで直接やりとりされ、サーバーには残りません。
- 通話中は自宅のパソコンに「通話中」と大きく表示されます。
- 緊急時の通報には使えません。119 番・110 番をご利用ください。

くわしい設計は [DESIGN.md](./DESIGN.md) をご覧ください。

## 手元で動かしてみる（Windows ノートパソコンでの手順）

### 1. 必要なものを入れる

[Node.js](https://nodejs.org/ja) の LTS 版（20 以上）をインストールしてください。
インストール後、「PowerShell」を開いて次を実行し、バージョンが表示されれば成功です。

```powershell
node -v
```

### 2. このプロジェクトを取ってくる

```powershell
git clone https://github.com/tmkhm18191726-eng/my-first-repo.git
cd my-first-repo\mimamori-call
npm install
```

### 3. 起動する

```powershell
npm run dev
```

`http://localhost:3000` と表示されたら、Chrome または Edge でそのアドレスを開いてください。

### 4. 画面を見る

| 開くアドレス                  | 何の画面か                       |
| ----------------------------- | -------------------------------- |
| `http://localhost:3000/`       | 入口（親用／自宅PC用を選ぶ）     |
| `http://localhost:3000/parent` | 親のスマートフォン用             |
| `http://localhost:3000/home`   | 自宅のパソコン用（待機画面）     |

止めるときは、PowerShell の画面で `Ctrl` + `C` を押してください。

## 秘密情報の扱い

パスワードや API キーは、**プログラムの中に直接書きません。**

- 手元で使う値 … `.dev.vars`（`.gitignore` に入っているので GitHub には送られません）
- 公開先で使う値 … `npx wrangler secret put 名前` で Cloudflare に登録します

`.dev.vars.example` には「どんな名前の設定が必要か」だけを書いてあります。
使うときはこれをコピーしてください。

```powershell
copy .dev.vars.example .dev.vars
```

※ フェーズ1 の段階では、まだ何も設定する必要はありません。
