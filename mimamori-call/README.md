# 見守り通話（mimamori-call）

子どもの帰宅時に、親のスマートフォンから自宅の Windows ノートパソコンへ
音声で話しかけられる、家族用の見守り Web アプリです。

- **会話は録音も保存もしません。**
- 声は端末どうしで直接やりとりされ、サーバーには残りません。
- 通話中は自宅のパソコンに「通話中」と大きく表示されます。
- 緊急時の通報には使えません。119 番・110 番をご利用ください。

くわしい設計は [DESIGN.md](./DESIGN.md) をご覧ください。

## 手元で動かしてみる（Windows ノートパソコンでの手順）

### 1. 必要なものを入れる

[Node.js](https://nodejs.org/ja) の LTS 版（20 以上）をインストールしてください。
インストール後、「PowerShell」を開いて次を実行し、バージョンが表示されれば成功です。

```powershell
node -v
```

### 2. このプロジェクトを取ってくる

```powershell
git clone https://github.com/tmkhm18191726-eng/my-first-repo.git
cd my-first-repo\mimamori-call
npm install
```

### 3. 起動する（PowerShell を **2つ** 開きます）

このアプリは「画面を配る係」と「つなぎ役（相手を見つける係）」の 2つで動きます。
PowerShell のウィンドウを2つ開いて、それぞれで1つずつ動かしてください。

**1つめの PowerShell（つなぎ役）**

```powershell
cd my-first-repo\mimamori-call
npm run dev:signal
```

`Ready on http://localhost:8787` と出れば成功です。

**2つめの PowerShell（画面）**

```powershell
cd my-first-repo\mimamori-call
npm run dev
```

`http://localhost:3000` と出れば成功です。

> どちらか片方だけだと動きません。画面には「準備中…」と表示されます。

### 4. 画面を見る

| 開くアドレス                   | 何の画面か                   |
| ------------------------------ | ---------------------------- |
| `http://localhost:3000/`       | 入口（親用／自宅PC用を選ぶ） |
| `http://localhost:3000/parent` | 親のスマートフォン用         |
| `http://localhost:3000/home`   | 自宅のパソコン用（待機画面） |

止めるときは、それぞれの PowerShell で `Ctrl` + `C` を押してください。

### 5. 動いているか確かめる（1台のパソコンだけでできます）

> ⚠️ **イヤホンを付けてから試してください。** 1台のパソコンで両方の画面を開くと、
> スピーカーの音をマイクが拾ってしまい、キーンという音（ハウリング）が出ます。

1. ウィンドウを2つ開き、片方で `/home`、もう片方で `/parent` を開く
2. `/home` で「待機開始」を押す
   - マイクの使用許可を聞かれるので **「許可」** を選ぶ
   - 「見守り通話待機中」と大きく出る
   - このとき画面上部は「マイクは切れています」のまま（待機中はマイクを使いません）
3. `/parent` に「自宅のパソコン：待機中（呼び出せます）」と出る
4. `/parent` で「接続する」を押す
   - 自宅PC側で **チャイムが鳴る**
   - 両方の画面が「通話中」になり、上部が赤い **「🔴 マイク使用中」** に変わる
   - 声を出すと、赤いバーが左右に動く
5. 「通話を終了する」を押す
   - 自宅PC側は5秒ほどで待機表示に戻り、マイク表示も「切れています」に戻る

つなぎ役の PowerShell を `Ctrl` + `C` で止めると、自宅PC の画面は「準備中…」に変わり、
もう一度 `npm run dev:signal` で起動すると、**何も操作しなくても** 待機中に戻ります。

## iPhone からつないでみる（ステップ1-4）

iPhone の Safari は、`https://` で始まるアドレスでないとマイクを使わせてくれません。
そこで **cloudflared** という無料の道具を使い、自宅パソコンに一時的な https アドレスを作ります。

作業はぜんぶ **自宅の Windows ノートパソコン** で行います。

### 1回だけの準備：合言葉を決める

インターネットに出すので、**アドレスを知っているだけでは入れないように**します。

```powershell
cd my-first-repo\mimamori-call
copy .dev.vars.example .dev.vars
notepad .dev.vars
```

メモ帳が開いたら、`ROOM_SECRET=` の右側に家族で決めた合言葉を書いて保存します。

```
ROOM_SECRET=hanako-taro-2026
```

- 名前や誕生日そのままは避けてください
- このファイルは GitHub には送られません（`.gitignore` に入れてあります）

### 1回だけの準備：cloudflared を入れる

PowerShell で次を実行します。

```powershell
winget install --id Cloudflare.cloudflared
```

`winget` が使えない場合は、[配布ページ](https://github.com/cloudflare/cloudflared/releases/latest)
から `cloudflared-windows-amd64.exe` をダウンロードし、`cloudflared.exe` という名前に変えて
`C:\Windows\System32` に置いてください。

入ったかどうかは、**PowerShell を開き直してから** 次で確認できます。

```powershell
cloudflared --version
```

### 毎回の手順（PowerShell を 2つ 開きます）

**1つめ：アプリを動かす**

```powershell
cd my-first-repo\mimamori-call
npm run preview
```

> ⏳ **このコマンドは、終わるまで1分ほどかかります。**
> 画面に次の行が出るまで、ブラウザを開かずに待ってください。
>
> ```
> Ready on http://localhost:8787
> ```
>
> この行が出る前にブラウザで開くと「このサイトにアクセスできません
> （ERR_CONNECTION_REFUSED）」になります。
>
> また、**この PowerShell は閉じないでください。** 閉じるとアプリも止まります。

（`npm run preview` は、画面とつなぎ役を **1つのアドレスにまとめて** 動かします）

**2つめ：インターネットからの入口を作る**

```powershell
cd my-first-repo\mimamori-call
npm run tunnel
```

しばらくすると、枠の中に次のようなアドレスが表示されます。

```
https://something-random-words.trycloudflare.com
```

**このアドレスを iPhone に送ってください**（自分宛のメールや LINE で送るのが簡単です）。

> ⚠️ このアドレスは cloudflared を止めるたびに変わります。テストのたびに送り直してください。

### 3. 自宅のパソコン側

Chrome か Edge で `http://localhost:8787/home` を開きます（トンネルのアドレスではなく、
こちらを使ってください。速くて安定します）。

1. 合言葉を入力する（1回だけ）
2. 「待機開始」を押す
3. マイクの使用許可を **「許可」** にする
4. 「見守り通話待機中」と大きく出れば準備完了

### 4. iPhone 側

**Safari** で、送っておいたトンネルのアドレスの後ろに `/parent` を付けて開きます。

```
https://something-random-words.trycloudflare.com/parent
```

1. 合言葉を入力する（1回だけ）
2. 「自宅のパソコン：待機中（呼び出せます）」と出るのを確認する
3. 「接続する」を押す
4. マイクの使用許可を **「許可」** にする

### 5. 確認すること

- [ ] 自宅パソコンで **チャイムが鳴る**
- [ ] 両方の画面が「通話中」になる
- [ ] **iPhone に向かって話すと、パソコンのスピーカーから聞こえる**
- [ ] **パソコンに向かって話すと、iPhone から聞こえる**
- [ ] パソコンの画面上部が赤い「🔴 マイク使用中」になり、声に合わせてバーが動く
- [ ] 「通話を終了する」で両方が終わり、マイク表示が消える

### 6. ホーム画面に追加する（任意）

iPhone の Safari で `/parent` を開いた状態で、下の共有ボタン → **「ホーム画面に追加」**。
アプリのように1タップで開けるようになります。

> ただし、トンネルのアドレスは毎回変わるため、ホーム画面への追加が本当に役立つのは
> フェーズ2（固定のアドレスで公開）からです。

### 7. テストが終わったら

**2つの PowerShell を両方とも `Ctrl` + `C` で止めてください。**
トンネルを止めると、外部からのアドレスは使えなくなります。

## うまくいかないときは

### まずこれを実行してください

別の PowerShell を開いて、次を実行すると、何が足りないかを日本語で教えてくれます。

```powershell
cd my-first-repo\mimamori-call
npm run check
```

`❌` が付いている行の「→」に書かれた対処を行ってください。

### 症状べつの対処

| 症状                                         | 対処                                                                     |
| -------------------------------------------- | ------------------------------------------------------------------------ |
| **「このサイトにアクセスできません」<br>ERR_CONNECTION_REFUSED** | アプリが動いていません。`npm run preview` の PowerShell で **`Ready on http://localhost:8787` が出るまで待って** から開いてください。`npm run check` で確認できます |
| iPhone で「マイクを使えません」と出る        | Safari で開いているか確認。設定 → Safari → マイク を「確認」か「許可」に  |
| iPhone で「安全な接続ではありません」と出る  | `http://` ではなく `https://` のトンネルのアドレスで開いてください        |
| 「自宅のパソコンが待機していません」と出る   | パソコンで `/home` を開き「待機開始」を押したか確認してください           |
| 「合言葉が違います」と出る                   | `.dev.vars` に書いた文字と同じか確認（前後の空白に注意）                  |
| 「準備中…」から進まない                      | `npm run preview` の PowerShell が動いているか確認してください            |
| 30秒待って「接続に失敗しました」と出る       | 回線の制限の可能性。Wi-Fi と携帯回線を切り替えて試してください（※）      |
| 音が聞こえない（画面は通話中）               | 「タップして相手の声を出す」ボタンが出ていたら押してください              |
| 1台のパソコンで試すとキーンと鳴る            | イヤホンを付けてください（スピーカーの音をマイクが拾っています）          |

※ この場合はフェーズ2で「中継サーバー（TURN）」を追加すると解決します。

## 秘密情報の扱い

パスワードや API キーは、**プログラムの中に直接書きません。**

- 手元で使う値 … `.dev.vars`（`.gitignore` に入っているので GitHub には送られません）
- 公開先で使う値 … `npx wrangler secret put 名前` で Cloudflare に登録します

合言葉（`ROOM_SECRET`）も同じ扱いです。合言葉が正しいかどうかの判定は
**必ずサーバー側で行っています**ので、画面側のプログラムを書き換えても通り抜けられません。

`.dev.vars.example` には「どんな名前の設定が必要か」だけを書いてあります。
使うときはこれをコピーしてください。

```powershell
copy .dev.vars.example .dev.vars
```

※ フェーズ1 の段階では、まだ何も設定する必要はありません。

```
    └─ worker/            つなぎ役サーバー（Cloudflare Workers で動く部分）
```

## 通話の流れ

```
親のスマホ                つなぎ役サーバー              自宅のパソコン
   │                    (Cloudflare Workers)              │
   │─── 接続する ──────────────▶│                          │
   │                            │──── 呼び出し ──────────▶│
   │                            │                    自動で応答
   │◀─── 相手が応答した ─────────│                          │
   │                                                       │
   └────────── ここから先は端末どうしが直接やりとり ────────┘
                 （音声。サーバーは通りません）
```

つなぎ役サーバーを通るのは「どこに繋げばよいか」という合図だけです。
**声そのものはサーバーを通らず、どこにも保存されません。**

## 録音していないことの確かめ方

このアプリには、音を保存するためのしくみ（`MediaRecorder`）が**一行も入っていません。**
次のコマンドで確認できます（説明文のコメント以外、何も出てきません）。

```powershell
findstr /s /i "MediaRecorder" src\*
```

マイクが入るのは通話中だけで、そのあいだは自宅パソコンの画面上部に
赤い「🔴 マイク使用中」が必ず出ます。通話が終わるとマイクは自動で切れます。
