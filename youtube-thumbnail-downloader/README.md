# YouTube サムネイル ダウンローダー（Chrome 拡張機能）

開いている YouTube 動画のサムネイルを、解像度別に一覧表示してワンクリックで保存する Chrome 拡張機能です。
Chrome ウェブストアには公開せず、自分の Chrome に直接読み込んで使います（審査は不要）。

## できること

- ツールバーのアイコンを押すと、今見ている動画のサムネイルを解像度別に一覧表示
- **最高画質を保存** ボタンで、その動画に存在する一番大きいサイズを自動で選んで保存
- `maxresdefault` / `sddefault` が**その動画に存在するかを自動判定**（無い場合はボタンが無効になる）
- 一覧ページや検索結果で**動画リンクを右クリック → サムネイルを保存（最高画質）**
- JPG / WebP の切り替え（WebP のほうがファイルサイズが小さい）
- 画像 URL のコピー
- 別の動画の URL・ID を貼り付けて保存することも可能

保存されるファイル名は `動画タイトル_動画ID_解像度.jpg` の形式です。
Windows で使えない文字（`\ / : * ? " < > |`）は自動で取り除かれます。

## 仕組み

YouTube のサムネイルは動画 ID から URL が決まる公開画像なので、その直リンクを組み立てて保存しているだけです。

| 解像度キー | サイズ | 備考 |
| --- | --- | --- |
| `maxresdefault` | 1280 × 720 | 無い動画もある |
| `sddefault` | 640 × 480 | 無い動画もある |
| `hqdefault` | 480 × 360 | 必ず存在する |
| `mqdefault` | 320 × 180 | |
| `default` | 120 × 90 | |

```
https://i.ytimg.com/vi/<動画ID>/maxresdefault.jpg
https://i.ytimg.com/vi_webp/<動画ID>/maxresdefault.webp   ← WebP 版
```

存在しない解像度をリクエストすると、YouTube は 404 を返すか 120×90 のグレー画像を返します。
この拡張機能は読み込めた画像の実寸を見て両方のケースを判定しています。

## インストール手順（Windows / Chrome）

1. このフォルダ `youtube-thumbnail-downloader` を、消さない場所に置く
   （例: `C:\Users\<ユーザー名>\chrome-extensions\youtube-thumbnail-downloader`）
   ※ 読み込み後にフォルダを移動・削除すると拡張機能が無効になります
2. Chrome のアドレスバーに `chrome://extensions` と入力して開く
3. 右上の **デベロッパー モード** をオンにする
4. 左上の **パッケージ化されていない拡張機能を読み込む** をクリック
5. 手順 1 のフォルダ（`manifest.json` が入っているフォルダ）を選択
6. ツールバーのパズルピースのアイコンから、この拡張機能をピン留めしておくと便利です

## 使い方

### ポップアップから

1. YouTube の動画ページを開く
2. ツールバーの赤いアイコンをクリック
3. **最高画質を保存** か、一覧から好きな解像度の **保存** をクリック

動画ページ以外を開いているときは、入力欄に URL か 11 文字の動画 ID を貼り付ければ使えます。

### 右クリックから

検索結果や関連動画の一覧で動画のサムネイル・タイトルを右クリックし、
**サムネイルを保存（最高画質）** を選ぶと、そのままダウンロードされます。
結果はツールバーアイコンのバッジ（`OK` / `!`）で表示されます。

## 保存先について

既定では Chrome のダウンロードフォルダに直接保存されます。
毎回保存先を選びたい場合は、ポップアップの **保存先を毎回きく** にチェックを入れてください。
設定は次回以降も保持されます。

## ファイル構成

```
youtube-thumbnail-downloader/
├── manifest.json           拡張機能の定義（Manifest V3）
├── common.js               URL 解析・ファイル名生成（共通ロジック）
├── download.js             保存処理（ポップアップと右クリックの共通部分）
├── popup.html/.css/.js     ツールバーのポップアップ
├── background.js           右クリックメニュー（サービスワーカー）
├── icons/                  アイコン 16/48/128px
└── tools/
    ├── make_icons.py       アイコンを生成し直すスクリプト
    └── test-common.mjs     common.js のテスト
```

## 開発

```bash
# ロジックのテスト（Node のみで動きます）
node tools/test-common.mjs

# アイコンを作り直す（標準ライブラリのみ・PIL 不要）
python3 tools/make_icons.py
```

コードを書き換えたあとは `chrome://extensions` でこの拡張機能の**再読み込みボタン**を押してください。

## 権限について

| 権限 | 用途 |
| --- | --- |
| `activeTab` | アイコンを押したときだけ、開いているタブの URL とタイトルを読む |
| `downloads` | 画像を保存する |
| `contextMenus` | 右クリックメニューを追加する |
| `storage` | JPG/WebP の選択と「保存先を毎回きく」設定を保存する |
| `https://i.ytimg.com/*` | サムネイルが存在するかを確認する |

閲覧履歴の収集や外部への送信は一切行いません。すべてローカルで完結します。

## 注意

サムネイル画像の著作権は各動画の権利者にあります。私的利用の範囲を超える使い方（無断転載など）はしないでください。
