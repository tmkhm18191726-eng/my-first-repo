# チャンネル状況ダッシュボード

複数のYouTubeチャンネル(自分のチャンネル＋ベンチマークしたいチャンネル)を、スマホでワンタップ切り替えながら状況確認できるWebアプリです。

## 使い方

1. アプリを開き、「設定」タブでYouTube Data API v3のAPIキーを入力する
   - [Google Cloud Console](https://console.cloud.google.com/)でプロジェクトを作成し、「YouTube Data API v3」を有効化してAPIキーを発行してください(無料枠で利用可能)
   - APIキーはこの端末のブラウザ内(localStorage)にのみ保存され、外部サーバーには送信されません
2. 「チャンネルを追加」にチャンネルのURL・`@ハンドル`・チャンネルIDのいずれかを入力し、「自分のチャンネル」か「ベンチマーク」を選んで追加する
3. 「状況」タブでチャンネルのチップをタップして切り替えると、登録者数・総再生数・動画数・ライブ配信中かどうか・最新動画の再生数とコメント数を確認できる

## スマホのホーム画面に追加する

PWA対応のため、ブラウザの「ホーム画面に追加」からアプリのように使えます(iOS Safari: 共有 → ホーム画面に追加)。

## 開発

```sh
npm install
npm run dev
```

## ビルド

```sh
npm run build
```
